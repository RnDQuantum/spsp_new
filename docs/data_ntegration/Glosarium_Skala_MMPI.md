# Glosarium Skala MMPI (untuk Data E.1 & E.2)

> **Disclaimer:** Dokumen ini adalah rangkuman istilah untuk membantu Anda (non-psikolog) memahami *apa yang diukur* tiap kode skala, bukan panduan interpretasi klinis. Angka T-score sebaiknya tetap ditinjau psikolog berlisensi sebelum dipakai untuk keputusan penting (rekrutmen, klinis, dll).

## Konsep Dasar

- **Raw score**: jumlah jawaban "benar/sesuai" pada item-item skala tertentu.
- **T-score**: skor mentah yang dikonversi ke skala standar, **rata-rata (mean) = 50, standar deviasi = 10**.
- Aturan umum (bukan mutlak): T-score **≥ 65** biasanya dianggap "elevated" (menonjol/perlu perhatian); 40–60 dianggap rentang rata-rata/normal.
- Skala validitas **selalu dicek lebih dulu** sebelum melihat skala klinis — untuk memastikan peserta menjawab jujur, konsisten, tidak melebih-lebihkan atau menutupi masalah.

## BAGIAN A — File E.2 ("MMPI 567", MMPI-2 standar/klasik)

### 1. Skala Validitas
| Kode | Arti | Mengukur |
|---|---|---|
| VRIN | Variable Response Inconsistency | Konsistensi jawaban acak/asal |
| TRIN | True Response Inconsistency | Kecenderungan menjawab "benar" atau "salah" terus tanpa membaca soal |
| F | Infrequency | Jawaban yang jarang dipilih orang pada umumnya (indikasi melebih-lebihkan/berpura-pura) |
| Fb | Back F | Versi F untuk paruh akhir tes (cek konsistensi sepanjang tes) |
| Fp | Infrequency-Psychopathology | Jawaban jarang dipilih bahkan oleh pasien psikiatri (deteksi "faking bad" lebih tajam) |
| Fs | Infrequency-Somatic | Keluhan fisik yang jarang dilaporkan bahkan oleh pasien medis |
| FBS | Symptom Validity ("Fake Bad Scale") | Potensi melebih-lebihkan gejala (sering dipakai konteks forensik/asuransi) |
| L | Lie | Kecenderungan menutupi kekurangan diri secara naif ("terlalu baik untuk jadi benar") |
| K | Correction | Sikap defensif/menutup diri secara lebih halus daripada L |
| S | Superlative Self-Presentation | Presentasi diri berlebihan positif |

## Catatan Penting untuk Pengembangan Aplikasi

1. **Bukan alat diagnosis mandiri.** T-score tinggi hanya menandakan area yang perlu ditinjau lebih lanjut, bukan otomatis "terdiagnosis". Idealnya laporan otomatis mencantumkan disclaimer ini.
2. **Cek dulu skala validitas** sebelum menampilkan/menginterpretasi skala lain — kalau F, Fp, VRIN, TRIN sangat tinggi, hasil skala lain bisa tidak dapat dipercaya.
3. **E.1 ("180") tampaknya bukan produk resmi Pearson/University of Minnesota** meski memakai penamaan skala gaya MMPI-2-RF. Sebaiknya dicek ke penyedia alat tes/vendor aplikasi Anda soal dasar keilmuan & lisensinya, karena ini menentukan seberapa valid norma T-score yang dipakai.
4. Untuk teks interpretatif otomatis (seperti di `semua_baris`, misalnya "Kemampuan mengendalikan emosi: kurang"), sebaiknya tetap melibatkan psikolog untuk memvalidasi kalimat/ambang batas yang dipakai, mengingat hasilnya berdampak pada penilaian orang sungguhan.
